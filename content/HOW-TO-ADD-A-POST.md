# Add a blog post in 5 steps

1. Open `content/posts/_TEMPLATE.md` on GitHub and copy all of it.
2. In the repo click Add file > Create new file. Name it `content/posts/your-post-slug.md`
   (lowercase, words joined by hyphens: this becomes the page address /blog/your-post-slug).
3. Paste the template and replace every line. Keep the three dashes (---) exactly as they are.
4. Click Commit changes. GitHub rebuilds and publishes the site in 2 to 4 minutes.
5. Open the new post, check it, then request indexing in Google Search Console.

Rules: category is any short word (AI, Security, SEO, Web Development, Cloud...). A new category appears
automatically. Dates are YYYY-MM-DD. Each source line is: Name | https://link
Put a blank line between paragraphs. Start list items with "- ". Start headings with "## ".
Never copy text from other sites. Write in your own words and link the source.
